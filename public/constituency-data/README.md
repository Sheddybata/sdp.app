# Constituency geography (Senatorial / Federal / State Assembly)

Generated by:

```bash
npm run extract-constituencies
```

**Sources (do not delete):**

- `public/agents/INEC 2026 List of Federal & State Constiuencies.xls`
- `public/agents/PU.xlsx` (reference; matching uses `location-codes.csv`)
- `public/location-codes.csv` (canonical State → LGA → Ward → PU)

**Outputs:**

| File | Purpose |
|------|---------|
| `senatorial.json` | 109 senatorial districts |
| `federal.json` | 360 federal constituencies |
| `state_assembly.json` | 989 state assembly seats |
| `constituency_links.json` | Seat → linked wards (for coverage / PU vs collation) |
| `unmapped.json` | Seats that still need manual ward links |
| `manual_links.json` | Admin overrides (never overwritten by extract; merged in) |
| `index.json` | Counts / generatedAt |

After editing `manual_links.json` (or using Admin → Constituency mapping), re-run the extract script when you want full ward metadata rebuilt from location-codes.
